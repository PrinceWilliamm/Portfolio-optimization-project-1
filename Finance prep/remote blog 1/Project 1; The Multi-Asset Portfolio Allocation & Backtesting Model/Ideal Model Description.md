## What is portfolio opitmization?
Portoflio optimization is pretty self explanatory term but in a packed response, Portfolio optimization tries to create the most optimal returns for a multi-asset investment portfolio with minimum risk.
	Achieved with risk measures and filteration techniwues for assets (see terminology)
## Model
Modern Portfolio Theory
	See terminology for further info
	Basically a theory that has some boundary conditions, but with taking them to account it creates an optimal portfolio with desired amount of risk
Some kind of a volatility/pressure model/measure
	Helps to see how the created portfolio performs under difficult market conditions e.g. Covid, tariff craziness etc.
