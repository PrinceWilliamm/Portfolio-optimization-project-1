## Volatility regime model
The model is ultimately used to create a variphying phase for the complete model. The model is described followingly:
	A volatility-aware portfolio research and backtesting framework that uses the S&P 500 implied volatility surface to identify changing market-risk regimes and evaluates a configurable multi-asset portfolio against the S&P 500 benchmark. Rather than requiring annual benchmark outperformance, the framework focuses on the portfolio's ability to deliver consistent long-term returns while controlling volatility, beta and drawdowns, particularly during periods of elevated implied volatility and equity-market stress. Users can modify the securities and allocation weights within each asset group, while the model automatically recalculates portfolio returns, annualized performance, beta, volatility, Sharpe and Sortino ratios, upside and downside capture, maximum drawdown, drawdown duration and stress-period performance
The model aims to create a significantly less volatile portfolio that can perform way better in the continuous bear market than SP500 with still making gains in the normal market and not falling behind too much in annual profit.
	Assets include for example SPY, VOO, VXUS, EFA, TLT, IeF, SGOV, BIL, GLD, DBC and a wild card that can be easily modified. These assets are just representatives of the clients needs and like said, can be modified rather effortlessly. Also the allocation can be varied by a huge bit to switch portfolio from a more aggressive to a more conservative one if needed.
Of course an ideal model wouldn't need changes as much as this one might need as this is still a first project of mine. Optimal model would most likely have conditional assets which would be targeted during bear market to reduce the volatility and boost performance during difficult times.
